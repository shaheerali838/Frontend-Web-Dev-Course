🔸 2. Introduction to Conditional Statements
• Conditional statements control the flow of a program based on conditions.
• They allow execution of different code blocks depending on whether conditions are true or false.
• Key types: if/else, switch, ternary operator.

🔸 3. if / else Statement
• The most basic conditional structure in JavaScript.
• if checks a condition; else runs if the condition is false.
• Commonly used for decisions like permissions or feature toggles.

🔸 4. Nested if / else
• Allows multiple levels of decision-making.
• Useful when checking ranges (e.g., grading systems).
• Can get complex quickly — keep readability in mind.

🔸 5. switch Statement
• Used for checking one variable against multiple values.
• Cleaner and more readable than long chains of if/else.
• Requires break after each case to stop execution.

🔸 6. Ternary Operator (?:)
• A shorthand for simple if/else.
• Best for inline conditions and value assignment.
• Not suitable for complex logic.

🔸 7. Practical Applications
• Checking if a user is old enough to vote.
• Grading system for student scores.
• Determining if today is a weekday or weekend.
• Theme switching (dark or light mode).

🔸 8. Tips & Best Practices
• Use if/else for binary conditions.
• Use switch for multiple fixed options.
• Use ternary for short, simple conditions.
• Keep code clean and avoid deeply nested logic.

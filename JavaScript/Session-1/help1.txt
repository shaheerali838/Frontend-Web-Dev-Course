🔸 1. Introduction to JavaScript
• JavaScript is the programming language of the web, used to make websites dynamic and interactive.
• Works with HTML (structure) and CSS (design) to complete the web technology stack.
• Runs directly inside browsers (Chrome, Firefox, Edge, Safari) without needing extra setup.
• Powers animations, interactive forms, games, apps, and full-scale web platforms.

🔸 2. How Browsers Run JavaScript
• Browsers contain a JavaScript Engine (e.g., Chrome → V8, Firefox → SpiderMonkey).
• JS code runs line by line, immediately after being loaded.
• It can manipulate the DOM (Document Object Model) to update HTML/CSS dynamically.
• JS is single-threaded but handles asynchronous tasks (like API calls) with the event loop.

🔸 3. Setting Up Environment
• Open the browser console (F12 → Console) to test small code snippets.
• Add JS inside HTML with <script> tags.
• Best practice: use an external file script.js linked in HTML (<script src="script.js"></script>).
• Use editors like VS Code for writing larger JS projects.

🔸 4. Code Structure
• JS code is made of statements, each usually ending with a semicolon ;
• Use comments: // single-line and /* multi-line */
• "use strict"; enables strict mode, catching silent errors and enforcing best practices.
• Example:
"use strict";
console.log("Hello, JavaScript!");

🔸 5. Practical Applications
• Show alerts: alert("Welcome to JavaScript!");
• Log data: console.log(5 * 5);
• Change background color:
document.body.style.background = "lightblue";
• Add interactivity: button click → show a message.

🔸 6. Tips & Best Practices
• Always start files with "use strict";
• Keep JS in separate files instead of mixing with HTML.
• Use clear file names (main.js, app.js, etc.).
• Debug frequently using the browser console.

🔸 7. Practice Activity

• In script.js, add:
– alert("Welcome to JavaScript!");
– console.log("This is my first JS program.");
– Change background color of the page.

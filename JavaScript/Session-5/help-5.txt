🔸 2. Introduction to Loops
• Loops allow us to repeat code multiple times.
• Useful when we want to avoid writing the same statement again and again.
• Types of loops in JavaScript:
– while loop
– do…while loop
– for loop

🔸 3. for Loop
• Most commonly used loop.
• Has three parts: initialization → condition → update.
• Example idea: Print numbers from 1 to 10 automatically.

🔸 4. while Loop
• Runs a block of code as long as a condition remains true.
• Example idea: Print numbers while a counter is less than 5.
• Be careful: if the condition never becomes false → infinite loop.

🔸 5. do…while Loop
• Similar to while, but guarantees the block runs at least once before checking the condition.
• Example idea: Show a welcome message at least once, even if the condition is false.

🔸 6. Loop Control Statements
• break → stops the loop immediately.
• continue → skips the current step and moves to the next.
• Example idea: Skip over a specific number when counting.

🔸 7. Practical Applications (only with what we’ve learned so far)
• Print your name 5 times.
• Print numbers from 1 to 10.
• Count down from 10 to 1.
• Print only even numbers between 1 and 10 using if + loop.
• Repeat a confirmation message until a certain number is reached.

🔸 8. Tips & Best Practices
• Always include a clear end condition to prevent infinite loops.
• Use for loops when the number of repetitions is known.
• Use while or do…while when waiting for a condition to change.
• Keep loops simple for readability.

🔸 2. Introduction to Functions
• Functions are blocks of code that can be reused.
• They make programs cleaner, easier to read, and avoid repetition.
• Functions can take inputs (parameters) and return outputs (values).

🔸 3. Function Declaration
• Standard way to create a function.
• Defined once, used many times.
• Example idea: A function that shows a welcome message.

🔸 4. Function Expressions
• Functions can also be stored inside variables.
• Useful when passing functions around or using them conditionally.
• Example idea: Store a greeting function inside a variable.

🔸 5. Arrow Functions (Basics)
• A shorter syntax for writing functions.
• Commonly used for simple tasks.
• Example idea: A function that doubles a number.

🔸 6. Default Parameters
• Functions can have default values for parameters.
• Example idea: A greeting function that defaults to “Guest” if no name is provided.

🔸 7. Practical Applications (with what we know so far)
• A function that prints your name and age.
• A function that checks if a number is even or odd.
• A function that runs a loop and prints numbers up to a given limit.
• A function that shows a different message based on a condition (student or not).

🔸 8. Tips & Best Practices
• Always give functions clear, descriptive names.
• Keep functions focused on one task.
• Reuse functions instead of repeating code.
• Use return when you need a result back from the function.

🔸 2. Introduction to Object Methods
• Object methods are functions stored as properties inside an object.
• They allow objects to perform actions and work with their own data.
• Declared directly inside objects for cleaner syntax and better structure.
• Example concept: a user object with a greet method uses its own data.
• Methods are essential for creating reusable, organized code in JavaScript.

🔸 3. Understanding the “this” Keyword
• The “this” keyword refers to the object that owns the method being executed.
• Inside a method, “this” gives access to the object’s properties and methods.
• The value of “this” depends on how a function is called, not where it is written.
• In regular functions, “this” may refer to the global object or be undefined in strict mode.
• Arrow functions don’t have their own “this” — they use the one from the outer scope.

🔸 4. Behavior of “this” in Different Contexts
• In object methods: “this” → the object itself.
• In regular functions: “this” → undefined in strict mode or global object otherwise.
• In DOM event handlers: “this” → the HTML element that triggered the event.
• In arrow functions: “this” → inherited from the surrounding scope.
• “this” changes when methods are copied or used as callbacks — must be handled carefully.

🔸 5. Practical Applications
• Creating user, car, or product objects with internal methods.
• Using “this” to access or update properties within the same object.
• Demonstrating how “this” changes when methods are reused across objects.
• Building dynamic methods like increaseSpeed(), login(), or toggleStatus() using “this”.

🔸 6. Tips & Best Practices
• Use “this” to make object methods flexible and dynamic.
• Avoid using arrow functions for object methods that rely on “this”.
• Keep your objects structured and readable with meaningful method names.
• Be cautious when using “this” inside nested or asynchronous functions.

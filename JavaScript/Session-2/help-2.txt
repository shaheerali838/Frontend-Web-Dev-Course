🔸 2. Introduction to Variables
• Variables are used to store and reuse values in a program.
• In modern JavaScript, we use let and const most of the time.
• var exists but is older and has scope issues, so it is less recommended.
• let → allows reassignment.
• const → fixed value after assignment (cannot be reassigned).

🔸 3. Data Types in JavaScript
• Number → includes integers, floats, NaN, Infinity.
• String → text inside quotes ("Hello", 'Hi', Template literal).
• Boolean → true or false values.
• Null → intentional empty value.
• Undefined → a variable declared but not assigned.
• Symbol → unique identifiers, often used for special object keys.
• BigInt → represents very large numbers beyond Number limits.

🔸 4. typeof Operator
• typeof shows the type of a value.
• Examples: typeof 42 → "number", typeof "Hi" → "string".
• typeof null returns "object" (special JS quirk).
• typeof undefined → "undefined".

🔸 5. Practical Applications
• Store user information (name, age, isLoggedIn).
• Count values with numbers (likes, scores, quantity).
• Use booleans for conditions (isDarkMode = true).
• Use null or undefined for unknown or not-yet-assigned values.

🔸 6. Tips & Best Practices
• Use const by default, let only when the value needs to change.
• Avoid var unless working with legacy code.
• Use clear and descriptive variable names (userName, totalPrice).
• Remember JavaScript is case-sensitive (age ≠ Age).

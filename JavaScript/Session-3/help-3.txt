🔸 2. Introduction to Type Conversions
• JavaScript values can change type when needed (conversion).
• Two types: Explicit (manual) and Implicit (automatic/coercion).
• Conversion is essential for working with user input, math, and conditions.

🔸 3. Explicit Conversions
• String(value) → Converts numbers, booleans, and other types to string.
• Number(value) → Converts strings and booleans to numbers.
• Boolean(value) → Converts values to true or false.
• Examples:
– String(123) → "123".
– Number("45") → 45.
– Boolean(0) → false, Boolean("Hello") → true.

🔸 4. Implicit Conversions (Type Coercion)
• Happens automatically when JavaScript expects a certain type.
• "5" + 2 → "52" (string concatenation).
• "5" - 2 → 3 (string converted to number).
• 1 + true → 2 (boolean true becomes 1).
• 0 == false → true (loose equality causes coercion).

🔸 5. Common Pitfalls
• Number("123abc") → NaN (Not a Number).
• Boolean("") → false, Boolean(" ") → true (space counts as a value).
• "0" == false → true, but "0" === false → false (strict vs loose equality).
• Always prefer strict equality (===) to avoid unexpected coercion.

🔸 6. Introduction to Operators
• Operators perform actions on values (operands).
• Categories: Arithmetic, Assignment, Comparison, Logical, and Advanced Operators.
• Operators are the backbone of calculations, comparisons, and logic in JS.

🔸 7. Arithmetic Operators
• + (addition), - (subtraction), * (multiplication), / (division).
• % (modulus → remainder).
• ** (exponentiation).
• ++ (increment), -- (decrement).
• Example: let x = 10; x % 3 → 1.

🔸 8. Assignment Operators
• = assigns values.
• +=, -=, *=, /= update variables with operations.
• Example: let score = 10; score += 5 → 15.

🔸 9. Comparison Operators
• == equal (performs type coercion).
• === strict equal (no coercion, preferred).
• != not equal, !== strict not equal.
• >, <, >=, <= for numeric comparisons.
• Example: 5 == "5" → true, but 5 === "5" → false.

🔸 10. Logical Operators
• && (AND) → true if both conditions are true.
• || (OR) → true if at least one condition is true.
• ! (NOT) → reverses the boolean value.
• Example: true && false → false.

🔸 11. Advanced Operators
• Nullish Coalescing (??) → returns first defined value.
– let user = null; console.log(user ?? "Guest") → "Guest".
• Optional Chaining (?.) → safely access nested properties.

🔸 12. Practical Applications
• Convert user input from string to number before calculations.
• Use comparison operators to validate form fields.
• Use logical operators to check multiple conditions (e.g., login success).
• Apply ?? for default values when user leaves a field empty.
• Use ?. to avoid runtime errors when accessing objects.

🔸 13. Tips & Best Practices
• Always use === instead of == to avoid coercion bugs.
• Use parentheses for readability in complex conditions.
• Don’t overuse ++ or -- inside conditions, it reduces readability.
• Apply ?? instead of || when dealing with empty strings or 0 (because || treats them as false).
